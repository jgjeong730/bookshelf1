# Project Template

이 폴더를 복사해 새 집필 프로젝트를 시작합니다.

```text
project-slug/
├─ project.md       # 목적·장르·독자·분량·핵심 질문
├─ planning/        # Gather·Design
├─ drafts/          # Draft·Revise 버전
├─ reviews/         # Dissect·Counsel·Reader
├─ research/        # 사실성·유사성 확인
├─ logs/            # 프롬프트·인간의 결정·변경 이력
└─ submission/      # Seal 결과물
```

프로젝트마다 `CURRENT PROJECT`의 목적과 출력 패키지를 이 파일과 맞춰 갱신합니다.
